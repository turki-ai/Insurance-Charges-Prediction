# Insurance Charges Prediction

A beginner-friendly data science project built to practice Exploratory Data Analysis (EDA) and Linear Regression using Scikit-Learn.

## Highlights
- **EDA & Visualization:** Analyzed dataset distributions and feature correlations using Pandas, Matplotlib, and Seaborn.
- **Preprocessing:** Handled categorical data with One-Hot Encoding (`pd.get_dummies`).
- **Modeling:** Trained a Linear Regression model and evaluated it using MAE, MSE, and $R^2$ Score.
- **Tech Stack:** Python, Scikit-Learn, Pandas, Seaborn.
